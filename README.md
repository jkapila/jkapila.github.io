# jkapila.github.io

Profile site for <https://jkapila.github.io/>. Plain HTML, no Jekyll (`.nojekyll`). Each project repo publishes its own Pages site under `/<repo>/`.

## Sitemaps

Hierarchy, submitted to Google Search Console as one URL:

```
sitemap-index.xml            <- submit only this
├── sitemap-profile.xml      <- pages in this repo (root page)
└── <repo>/sitemap.xml       <- one per project, generated by that repo
```

Rules:

- Every sitemap lives on `https://jkapila.github.io`. A sitemap may only list URLs inside its own folder, so `/mltreelib/sitemap.xml` lists only `/mltreelib/...`.
- Each project repo generates its own sitemap in its CI (mltreelib: `scripts/generate_sitemap_and_aeo.py`) with `BASE_URL = "https://jkapila.github.io/<repo>"`.
- Do not list `jitinkapila.com`. It is a different host with its own index.

### Add a project

1. In the project repo: publish the Pages site and a `sitemap.xml` at its root. Check `https://jkapila.github.io/<repo>/sitemap.xml` returns 200.
2. Here: add one entry to `sitemap-index.xml`:

   ```xml
   <sitemap>
     <loc>https://jkapila.github.io/<repo>/sitemap.xml</loc>
   </sitemap>
   ```

3. Add a card for it in `index.html`.
4. `xmllint --noout sitemap-index.xml sitemap-profile.xml`, commit, push.
5. After deploy, run `scripts/check.sh` (every sitemap must show http=200).
6. In Search Console (property `https://jkapila.github.io/`), resubmit `sitemap-index.xml` and also submit the project sitemap directly as a backup.

### Add a page to this repo

Add a `<url><loc>…</loc></url>` to `sitemap-profile.xml`.

### Search Console setup

- Property type: URL prefix, `https://jkapila.github.io/`. github.io has no DNS access, so verify with the HTML file (`google<token>.html` in the repo root) or a `<meta name="google-site-verification">` tag in `index.html`. Keep it in place afterwards.
- `robots.txt` carries `Sitemap:` lines for the index and each project sitemap.
